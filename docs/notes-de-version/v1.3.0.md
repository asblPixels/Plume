## Plume 1.3.0 — Polices scolaires et Plume partout

Plume, le traitement de texte libre de Pixel's ASBL, s'installe désormais **sur tous les appareils** et accueille les **polices de l'école**.

**Nouveautés**
- **Polices scolaires intégrées** : cursives françaises (*Playwrite FR Moderne* et *Trad*), *Andika* (lecture), *OpenDyslexic*, *Comic Neue*, *Atkinson Hyperlegible*, *Lexend*
- **Ajoutez vos polices** (par exemple Marelle) : liste des polices → « Ajouter une police… »
- **Export PDF direct** partout, même sur tablette et téléphone (bouton PDF en haut, `Ctrl+Maj+P`)
- **Guide « Bien démarrer »** en mots simples (onglet Aide)
- **Nouvelles versions** : Android, iPhone/iPad, Flatpak, Snap
- Sur téléphone : enregistrement dans *Documents › Plume*, bouton **Partager**, « Ouvrir avec Plume » depuis les autres applications

**Quel fichier choisir ?**

| Appareil | Fichier |
|---|---|
| Windows 10/11 | `Plume-Setup-…-x64.exe` (installation sans droits administrateur) ou `Plume-Portable-…-x64.zip` |
| Android | `Plume-…-android.apk` (autoriser l'installation d'applications inconnues) |
| iPhone / iPad | Le plus simple : ouvrir **asblpixels.github.io/Plume** dans Safari → Partager → *Sur l'écran d'accueil*. Le fichier `.ipa` n'est pas signé : il ne s'installe qu'avec un outil comme AltStore ou Sideloadly. |
| Linux | `.AppImage` (toutes distributions), `.deb` (Debian/Ubuntu/Mint), `.rpm` (Fedora), `.flatpak`, `.snap` |
| Sans installation | **https://asblpixels.github.io/Plume/** |

> Windows : le fichier n'est pas signé numériquement. Au premier lancement, cliquez sur *Informations complémentaires → Exécuter quand même*.
