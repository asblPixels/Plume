# Plume 1.4.1

Plume conserve les champs texte, cases à cocher et listes déroulantes Word pris en charge. Le panneau VBA affiche le code et les procédures détectées. Le lancement manuel passe par Microsoft Word. Les PDF retouchés gardent une couche sélectionnable pour les fragments pris en charge.

## Téléchargements

- Windows x64 dispose d’un installateur et d’une édition portable non signés.
- Linux x64 dispose des formats AppImage, DEB, RPM, Snap et Flatpak.
- Android dispose d’un APK d’installation directe, signé avec la clé de débogage du build. Une installation existante signée avec une autre clé ne peut pas être mise à jour avec cet APK.
- macOS dispose d’images disque DMG pour Mac Intel et Apple Silicon, sans notarisation.
- L’IPA iOS est fournie sans signature.
- La version navigateur est disponible sur [Plume en ligne](https://asblpixels.github.io/Plume/).

La fidélité de tous les documents Word et PDF complexes et l’exécution VBA intégrée restent en développement.
