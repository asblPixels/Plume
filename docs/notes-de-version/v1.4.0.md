# Plume 1.4.0 — Marelle, Borel et compatibilité Word renforcée

## Nouveautés
- **Polices Marelle et Borel** intégrées (cursives scolaires). Les polices scolaires sont **jointes au document** `.docx` / `.odt` : il s'affiche correctement dans Word, même sans la police installée
- **Pages comme dans Word** : les paragraphes se coupent à la ligne, sections en portrait et paysage, texte en colonnes
- **Graphiques, SmartArt, formes et équations modifiables** (double-clic)
- **Commentaires** avec réponses et « résolu » ; **suivi des modifications** complet
- **Styles de tableau** (en-tête coloré, lignes alternées), fichiers avec macros (`.docm`) conservés, anciens `.doc` mieux lus
- **Démarrage sur une page d'accueil** : document vierge ou ouverture d'un fichier (par ex. sur clé USB). Plume ne rouvre plus le dernier document et **ne garde rien sur l'ordinateur** (idéal à l'école)
- **Mises à jour automatiques** : la version en ligne et les applications Windows / Linux se mettent à jour seules ; Android et iPhone préviennent quand une nouvelle version sort

**Corrigé** : tableaux qui dépassaient de la page, textes de zones de texte en double, export `.odt` de certaines listes

## Téléchargements

| Appareil | Fichier |
|---|---|
| Windows 10/11 | `Plume-Setup-…-x64.exe` (installation sans droits administrateur) ou `Plume-Portable-…-x64.zip` |
| Android | `Plume-…-android.apk` (autoriser l'installation d'applications inconnues) |
| iPhone / iPad | Le plus simple : ouvrir **asblpixels.github.io/Plume** dans Safari → Partager → *Sur l'écran d'accueil*. Le fichier `.ipa` n'est pas signé (AltStore, Sideloadly). |
| Linux | `.AppImage`, `.deb`, `.rpm`, `.flatpak`, `.snap` |
| Sans installation | **https://asblpixels.github.io/Plume/** |

> Windows : le fichier n'est pas signé numériquement. Au premier lancement : *Informations complémentaires → Exécuter quand même*.
